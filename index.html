Regras do parser

O que é contado

  • Apenas IMG. Contam anexos JPG, JPEG e PNG. STK, VID, OPUS e outros ficheiros não contam; uma legenda sem data não esconde a linha IMG.
  • Mesmo remetente + mesmo minuto. Registos de imagem consecutivos passam a contar como um fino, mesmo com linhas de sistema pelo meio.
  • Números isolados são só uma verificação. O maior total manual nunca altera a atribuição nem a contagem.
  • A correspondência telefónica é exata após limpeza. Nomes guardados ficam visivelmente pendentes até serem associados.
  • O dia vai das 08:00 às 08:00. Fotografias antes das 08:00 pertencem ao período anterior.
